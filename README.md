# LaborNapló – OTP bejelentkezés

A Microsoft Entra External ID e-mailes egyszer használatos kódos bejelentkezéséhez szükséges frontendfájlok.

A telepítés részletei a `TELEPITES.md` fájlban találhatók.

A csomag nem tartalmazza és nem módosítja a meglévő API-t, Azure Static Web Apps GitHub Actions workflow-t, `styles.css` vagy `app.js` fájlokat.
