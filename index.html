Belépés e-maillel

Add meg az e-mail-címedet a Microsoft biztonságos bejelentkezési oldalán. Egy egyszer használatos kódot küldünk a postaládádba.

A bejelentkezés beállítása még nincs kész. Az Entra External ID bérlő és az alkalmazásazonosító beállítása után itt jelenik meg a belépés gomb.

Első belépéskor az e-mail-címed ellenőrzése után automatikusan létrejön a fiókod. Nem kell jelszót választanod vagy Microsoft-fiókot készítened.

▣ A belépést a Microsoft Entra External ID kezeli.
